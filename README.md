# Hunkkngor Creative Studio

Responsive static website built with HTML, CSS and JavaScript.

## Included
- `index.html` — website content and sections
- `styles.css` — design and responsive mobile layout
- `script.js` — mobile navigation, current year and contact email

## Before publishing
1. Open `script.js` and replace `YOUR_EMAIL@example.com` with your preferred business email.
2. Replace the sample portfolio panels in `index.html` with your real projects, images and links when ready.
3. Test the website on your phone.

## Deploy with Netlify and GitHub
1. Upload these four files to the root of your `hunkkngor-creative-studio` GitHub repository.
2. In Netlify, select **Add new project** → **Import an existing project**.
3. Connect GitHub and select `hunkkngor-creative-studio`.
4. Leave the build command empty and set the publish directory to `.` (repository root).
5. Deploy. Future pushes to the connected branch can trigger new deploys.

No framework, package installation or build step is required.
